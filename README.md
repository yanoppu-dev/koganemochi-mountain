# 小金持ち山登り

**プロジェクト分類：ブラウザゲーム制作**

お金を拾いながら、足場を跳んで山頂を目指すHTMLゲームです。

## 現行版と使い方

- ソース：[index.html](index.html)（mainブランチ）
- 左右キーで移動、上キーまたはスペースでジャンプ。画面のタッチ操作にも対応。
- HTMLファイルを保存し、ブラウザーで開きます。追加のインストールは不要です。
- 配信サイトの公開版との一致や動作確認は別途確認します。
